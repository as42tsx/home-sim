# M1 验收记录

日期：2026-09-30。分支 `main`，合并 `view3d` 之后的工作区。未推送。

环境：Chrome `/usr/bin/google-chrome`，参数 `--no-sandbox --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`。桌面视口 1440×900，手机视口 390×844（`isMobile`、`hasTouch`，不是真机 Safari）。页面由 `python3 -m http.server 8766` 提供，地址 `http://127.0.0.1:8766/home-sim/`。

| 检查 | 结果 |
| --- | --- |
| `node --test` | 75 通过，0 失败 |
| `node scripts/cleanroom-check.js` | 通过 |
| `npm run e2e` | 退出码 1。12 个故事脚本通过；`e2e/us-09a.mjs` 与 `e2e/perf.mjs` 只因帧率未达到阈值失败。每个脚本都打印了 `PASS CONSOLE`（桌面和手机加载无页面错误） |

Swiftshader 是 CPU 渲染。下面的 fps 是这条路径上的下限，不是中端笔记本上的数字。阈值没有改。

## 给 Naomi / Luna 的未决项

1. 项目许可证仍等所有者决定。README 写明了这一点，仓库里没有 LICENSE。PRD US-11 AC5 和 M1 交付物第 ⑩ 项写的是 README 附带 LICENSE。
2. 模板面积：设计表是中线、容差 ±0.1 m²；PRD US-01 AC3 写的是 ≤ 0.01 m²。实测中线最大偏差 0.050 m²。模板未改。界面上的使用面积是内净。
3. M1 交付物写「自研家具（约 60 件）」。当前 `src/furniture/catalog.js` 是 23 种通用块，注释说明等批次 2 的家具库。
4. US-11 AC1（推送后 5 分钟内 Pages 生效）和 AC4（Fast 4G ≤ 1.5 s、桌面 Lighthouse ≥ 90）这次没有测。
5. US-07 AC2 的 50 fps 和 US-09a AC2 的 30 fps 需要在有 GPU 的中端笔记本上再量一次。这次 14.67 fps 和 19.3 fps 只说明 Swiftshader 上的下限。
6. US-09a 的参考环境是 iPhone 12 Safari。这次是 Chrome 手机仿真。
7. 手机分享页小房间的文字互相重叠，见上面的截图。是否改标签密度留给设计。
